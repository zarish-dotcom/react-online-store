# React Online Store

A React.js-based e-commerce web application developed as an academic project.

## Features

- User Login and Signup
- User Logout
- Product Categories
- Product Search
- Add to Cart
- Wishlist
- Place Orders
- User Profile
- Product Reviews
- Order History

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Project Status

Completed as an academic project.
